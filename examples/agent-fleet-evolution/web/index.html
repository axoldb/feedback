What this demonstrates
Two deterministic agents propose complete FleetPlans. The application computes routes, validates and scores them, then applies bounded Generation 1 variation. AxolDB persists Scenario, FleetPlans, AgentStates and atomic membership checkpoints.
FleetPlan mutation and crossover are application operations. Native integer mutation and binary midpoint crossover have a separate typed fixture. Application parent references are not native Evolution lineage.
Recorded replay proves evaluation of retained inputs, not identical future model generation. The optional historical local LLM pilot produced 15 valid copies of one cost-28 plan; none was admitted and no optimization benefit was measured.
