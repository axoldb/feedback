# Data licence and provenance

The eight English source snapshots in `data/documents.json` are short extracts from named GOV.UK
benefit guides retrieved through the GOV.UK Content API on 2026-10-08. Each record retains the
public page URL, API URL, GOV.UK content ID and source publication timestamp.

GOV.UK states that its published content may be reused under the Open Government Licence. The
licence permits copying, publication, distribution and adaptation subject to attribution and its
listed exclusions:

- GOV.UK reuse guidance: https://www.gov.uk/help/reuse-govuk-content
- GOV.UK terms: https://www.gov.uk/help/terms-conditions
- Open Government Licence v3.0: https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/

Required attribution used by this example:

> Contains public sector information licensed under the Open Government Licence v3.0.

No logo, image, personal data or identified third-party material is included. The data snapshot is
licensed under OGL v3.0; it is not relicensed by the MIT licence that applies to the example code.

The preferred Manifesto Project corpus was not included. Its API requires registration and an API
key, and its official terms prohibit redistribution without written authorization. The example did
not request, embed or bypass such credentials.
