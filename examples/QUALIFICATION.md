## API feasibility result

Public Server v1 supports Population create/read, Generation read, genotype insert/read,
Transaction publication, Fork create/read/history, Query, security and credentials. It does not
support external Fork descendant publication or remote Evolution execution. Native Fork
advancement requires a real Evolution Run. Both examples therefore use two Populations and store
an explicit source Population ID, Generation ID and state root in each branch manifest. PostgreSQL
was never accessed by the examples.

Each example uses strict HTTPS with the exact instance CA, hostname validation, a protected
credential file, a one-MiB Server request boundary, and ordinary inline Transaction content. Its
small generations do not need the supported Generation Preparation flow.
