# AxolDB feedback

This public repository is the feedback channel for the experimental **AxolDB Developer Preview**.
Use it to report reproducible bugs or propose focused product improvements.

Before opening an issue:

1. [Search open and closed issues](https://github.com/axoldb/feedback/issues?q=is%3Aissue) for the
   same symptom or request.
2. Choose the bug-report or feature-request form and complete its requested fields.
3. Remove credentials, private prompts, personal or production data, complete databases,
   unrestricted logs, and unsanitized diagnostic bundles.
4. State observed behavior separately from any suspected cause.

This channel is for reports and suggestions, not source-code contributions. Submission does not
promise a response time, fix, release date, support service level, or bounty.

## Security-sensitive findings

Do **not** file vulnerabilities, exploit details, credentials, or other sensitive security material
as public issues. `office@axoldb.com` is the designated confidential security contact, but its
configuration and delivery have not yet been verified. Until the owner confirms that verification,
do not send sensitive details to the address or post them here. Retain the material privately and
follow the current [security notice](SECURITY.md).

## Coding agents

Coding agents should follow [AGENTS.md](AGENTS.md). Use only the user's own authorized GitHub
access, search for duplicates first, preserve the form's field structure when using an API or CLI,
and return the created issue URL to the user. A user's explicit standing authorization may cover
submissions without separate approval for every ticket; this repository does not itself grant that
authorization. Never fabricate reproduction evidence or automatically submit repeated issues.
